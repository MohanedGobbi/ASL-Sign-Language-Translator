Features

Real-Time Recognition

Detects the full ASL alphabet (A–Z) frame-by-frame using MediaPipe hand tracking and geometric classification.

Hold-to-Confirm

Hold a sign steady for 0.8s to confirm it — no accidental letters from transitional hand shapes.

Sentence Builder

String letters into words, words into sentences, and browse your word history as you sign.

Text-to-Speech

One click reads your translated sentence aloud using the browser's native Web Speech API.

Guided Practice

Target letters with form hints, live match feedback, score & streak tracking, and an alphabet progress grid.

100% Local

All AI processing runs in your browser via WebAssembly. No video data is ever sent to a server.

How It Works

1

Allow camera access

Open Translate or Practice and grant webcam permission. The AI model loads in seconds.

2

Show your hand

MediaPipe tracks 21 hand landmarks per frame and the classifier scores every ASL letter shape.

3

Hold to confirm

Keep the sign steady for 0.8s. In Translate it's added to your sentence; in Practice it scores a point.

Tech Stack

  • Hand Tracking — Google MediaPipe Tasks Vision (WebAssembly, GPU)
  • Frontend — Vanilla HTML / CSS / JavaScript (ES Modules)
  • Build Tool — Vite
  • Audio — Web Speech API

Accuracy Notes

  • Use a well-lit environment for optimal hand tracking.
  • Some letters look similar to the camera (U/V, M/N) — sign clearly and deliberately.
  • J and Z require motion, so they are excluded from Practice mode.
